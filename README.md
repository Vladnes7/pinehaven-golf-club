# Pinehaven

Русскоязычный портфолио-сайт вымышленного лесного гольф-клуба. Семь основных страниц, две информационные, оригинальные изображения и работающие демонстрационные сценарии. Статический HTML, CSS и небольшие JavaScript-модули, без стороннего фреймворка и зависимостей во время работы.

## Локальный запуск

Требуется Node.js 20 или новее. Устанавливать зависимости не нужно.

```sh
npm run build
npm start
```

Откройте http://127.0.0.1:4500/. Для другого порта: `PORT=4501 npm start`. Сервер доступен только на вашем компьютере. Готовые HTML-файлы включены в репозиторий.

## Возможности

- Многослойный первый экран, траектория мяча, движение фотографий при прокрутке и сквозной индикатор прогресса.
- Округлые кнопки со световым бликом, подсветкой, состояниями клавиатурного фокуса и нажатия.
- 18 различных изображений лунок с линиями игры, характеристиками, клавиатурным управлением и счётной карточкой CSV/печать.
- Запись в четыре шага, календарь гостевых стартов, сезонные тарифы, допуслуги и групповые пакеты.
- Пять категорий членства, калькулятор, подбор и дорожка вступления.
- Академия с выбором занятия и тренера, меню ресторана, фотогалерея клубного дома, FAQ и концептуальная схема проезда.
- Мобильные композиции и поддержка `prefers-reduced-motion`.

## Страницы

`/`, `/course/`, `/visitors/`, `/membership/`, `/academy/`, `/clubhouse/`, `/contact/`, `/privacy/`, `/terms/`.

## Демонстрационные данные

Клуб, местоположение, тренеры, события и цены вымышлены. Расписание моделируется в браузере, даты считаются по Europe/Moscow. Формы валидируются, но не отправляют и не сохраняют личные данные. Оплата не подключена, настоящая бронь не создаётся. Фотографии сгенерированы специально для проекта.

## Исходники

| Путь | Назначение |
| --- | --- |
| `src/pages.mjs`, `src/components.mjs` | Шаблоны страниц и общие блоки |
| `build.mjs` | Генерация HTML и счётной карточки |
| `assets/app.mjs`, `assets/experience.mjs` | Сценарии, взаимодействия и движение |
| `assets/logic.mjs` | Даты, места, тарифы и расчёты |
| `assets/course.mjs` | Лунки и SVG-линии игры |
| `assets/style.css`, `assets/experience.css`, `assets/finishing.css` | Базовое оформление и визуальные доработки |
| `assets/images/`, `assets/fonts/` | Локальные изображения и шрифт |
| `tests/` | Проверки расчётов, изображений и сборки |

После редактирования шаблонов выполните `npm run build`. Для просмотра нужен HTTP, открытие через `file://` не поддерживается.

## Проверки

```sh
npm test
```

Проверяются календарь и часовой пояс, доступность, сезонные тарифы, допуслуги, членство, уникальность изображений лунок и ресурсы готовых страниц. Материалы и лицензия шрифта описаны в [ASSETS.md](ASSETS.md).

## Статическое размещение

Готовые папки страниц и `assets/` можно разместить в корне статического сайта. При размещении в подпапке необходима настройка базового пути. Все изображения и шрифты поставляются локально.
